## 一句话总结

针对现有对比解码方法（如 VCD、ICD）对全局视觉或文本输入施加**无差别扰动（Holistic Input Disturbance）** 从而引入随机不确定性噪声、在贪心解码下甚至损害简单视觉识别且使推理耗时翻倍的缺陷，提出**自省式解码（Self-Introspective Decoding, SID）** 及其核心组件**上下文与文本感知 Token 选择策略（$\text{CT}^2\text{S}$）**：在对比负分支中，先让前 $i$ 层解码器层（如 LLaVA-1.5 的前 3 层）正常完成早期跨模态上下文融合，随后利用当前待预测位置（最后一个 Token `[-1]`）的跨头平均自注意力分数，**反直觉地剪除高关注度前景 Token、仅保留约 10% 注意力最低的次要/背景视觉 Token** 输入后续解码层；这一设计既精准诱发了由背景上下文与文本历史共同驱动的**跨模态关联幻觉（Vision-and-Text Association Hallucination）** 以便在对比相减时将其抵消，又砍掉了负分支后 $L-i$ 层中 90% 的视觉 Token 计算量，在 LLaVA-1.5 / InstructBLIP / Shikra / LLaVA-NeXT 四大架构上全面刷新 CHAIR 与 POPE 纪录，同时比 VCD/ICD **提速约 30%**。

## 核心贡献

1. **揭示全局输入扰动对比解码（VCD / ICD）的两大根本局限**：
   - **与图文语义无关的盲目不确定性噪声**：通过实验（表 1）证明，VCD（全局图像加高斯噪声）与 ICD（添加负面角色指令）对输入施加无差别扰动，在**贪心解码（Greedy）** 下评测简单子集（POPE Random）时准确率（`87.8%` / `87.9%`）反而**低于**不加任何干预的标准贪心解码（`88.8%`）；而在**采样解码（Sampling）** 下，一旦移除自适应合理性约束（Adaptive Plausibility Constraint, APC），VCD 与 ICD 的性能立即崩塌至基线以下（Random 从 `84.9%` 跌至 `83.3% / 82.7%`，$\text{CHAIR}_s$ 恶化至 `51.9 / 52.2`），说明其性能收益高度依赖后处理截断而非精准的幻觉建模。
   - **双倍全序列前向计算开销**：负分支同样需要处理完整的 $576$（或 $2304$）个视觉 Token，导致推理延迟接近原模型的 $2\times$。
2. **提出与 Token 剪枝方向相反的“上下文与文本感知 Token 选择（$\text{CT}^2\text{S}$）”**：不同于传统加速剪枝（如 FastV）保留高注意力 Token、也不同于 AVISC 将高注意力“盲点 Token”作为负分支，SID 指出：在解码器前 $i$ 层完成初步图文交互后，**仅保留注意力最低的 Top-$k\%$（默认 10%）视觉 Token**，能够抹去当前问题真正关注的前景目标，同时保留场景背景线索，从而最有效地激发模型基于“残余视觉背景 + 历史生成文本”产生的虚假共现幻觉。
3. **兼具 SOTA 幻觉抑制、通用多模态能力无损与 ~30% 推理加速**：由于负分支在第 $i=3$ 层后裁掉了 90% 的视觉 Token，SID 将对比解码的额外计算开销压缩了约 **30%**（在 V100 上耗时从 VCD 的 `904s` 降至 `668s`，额外显存仅 `+94 MB`），并且在抑制幻觉的同时不损伤甚至提升了 MME（`1510.8 -> 1520.4`）、MMBench、MathVista、MMVet 与 MMMU 等通用多模态评测基准。

## 1. 问题诊断：为什么 VCD 与 ICD 的全局输入扰动不够好？

### 1.1 视觉对比解码（Contrastive Decoding）的标准形式与合理性截断

给定视觉输入 Token 序列 $v$、文本指令 $t$ 以及已生成前缀 $y_{<i}$，自回归 LVLM 的下一步预测分布为 $p_\theta(y_i \mid v, t, y_{<i}) = \mathrm{softmax}(\mathrm{logit}_\theta(y_i \mid v, t, y_{<i}))$。为抑制幻觉，对比解码（CD）引入一个受扰动的负向输入 $(v_d, t_d)$，通过在对数空间放大原分布并减去负分支分布来修正预测：

$$
p_{\text{cd}}(y_i \mid v, v_d, t, y_{<i}) = \mathrm{softmax}\!\Big[(1 + \alpha)\,\mathrm{logit}_\theta(y_i \mid v, t, y_{<i}) - \alpha\,\mathrm{logit}_\theta(y_i \mid v_d, t_d, y_{<i})\Big]
$$

其中 $\alpha > 0$ 为对比强度超参数。为了防止当某个真实目标词在原分布和负分布中同时具有高概率、或者某个荒谬词在负分布中概率极低时被错误放大（即假阳性奖励），CD 必须配合**自适应合理性约束（Adaptive Plausibility Constraint, APC，论文式 3）** 对候选词表进行截断：

$$
\mathcal{V}_{\text{token}}(y_{<i}) = \left\{ y_i \in \mathcal{V} \;:\; p_\theta(y_i \mid v, t, y_{<i}) \ge \beta \max_{\omega \in \mathcal{V}} p_\theta(\omega \mid v, t, y_{<i}) \right\}
$$

对于 $y_i \notin \mathcal{V}_{\text{token}}(y_{<i})$，直接将其对比对数几率置为 $-\infty$。

### 1.2 全局扰动（VCD / ICD）的失效机理验证

作者在 MSCOCO POPE 的 Random（随机负样本，测试基础前景识别）与 Adversarial（高共现对抗负样本，测试关联幻觉）两个子集上，对 LLaVA-1.5 7B 进行了剥离 APC 约束（`w/o Eq. 3`）及切换采样/贪心解码的诊断实验（表 1）：

| 解码方式与方法 | Random Acc $\uparrow$ | Random F1 $\uparrow$ | Adversarial Acc $\uparrow$ | Adversarial F1 $\uparrow$ | 诊断结论 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Sampling（直接采样，$\beta=1$）** | 84.9 | 83.2 | 78.7 | 78.9 | 采样随机性导致性能显著低于贪心 |
| **VCD (Sampling, $\alpha=1.0, \beta=0.1$)** | 87.7 | 87.6 | 80.6 | 81.9 | 依赖 APC 截断过滤采样噪声 |
| **VCD w/o Eq. 3（移除 APC）** | 83.3 | 80.5 | 76.2 | 75.8 | **移除截断后全面跌破直接采样基线** |
| **ICD w/o Eq. 3（移除 APC）** | 82.7 | 81.6 | 75.4 | 76.7 | **移除截断后同样严重退化** |
| **SID（本文，Sampling）** | **89.3** | **89.4** | **82.6** | **83.7** | 全面领先 VCD / ICD |
| **SID w/o Eq. 3（移除 APC）** | 87.4 | 86.4 | 80.5 | 79.8 | **即使移除 APC 仍显著优于采样基线** |
| **Greedy（标准贪心解码）** | 88.8 | 88.5 | 79.3 | 80.9 | 简单子集已很强，对抗子集受共现幻觉困扰 |
| **VCD (Greedy)** | 87.8 | 87.9 | 80.9 | 82.0 | **在简单 Random 子集上反而损害了原模型（-1.0%）** |
| **ICD (Greedy)** | 87.9 | 87.8 | 80.2 | 81.3 | **在简单 Random 子集上同样出现倒退（-0.9%）** |
| **SID（本文，Greedy）** | **89.5** | **89.7** | **83.3** | **84.2** | **在简单与对抗子集上双双显著提升** |

这一实验揭示了全局扰动的致命缺陷：向整张图注入高斯噪声（VCD）或加入负面指令（ICD）并不知道当前文本正在询问哪个目标，其诱导出的负分支分布 $p_\theta(y_i\mid v_d, t, y_{<i})$ 包含大量**与当前语义无关的随机不确定性噪声**。当图像目标本就清晰（如 Random 子集）且使用贪心解码时，负分支中残存的正确目标概率或随机噪声在相减后反而削弱了原本正确的预测峰值；只有在移除与当前文本目标强相关的前景视觉区域、同时保留诱发共现联想的背景区域时，负分支才能真正充当“幻觉放大器”。

## 2. 核心方法：自省式解码（SID）与 $\text{CT}^2\text{S}$ 策略

### 2.1 自省式跨模态注意力评估（Self-Introspective Assessment）

LVLM 的自回归解码器由 $L$ 层因果 Transformer 层堆叠而成。在第 $i$ 层解码器层中，设多头因果自注意力（Causal Self-Attention）包含 $h$ 个注意力头，每个头的隐藏维度为 $d_l = d / h$，输入序列由系统提示、$N$ 个视觉 Token $v$、用户指令 $t$ 以及已生成文本 $g = y_{<t}$ 拼接而成。查询矩阵 $\mathbf{Q} \in \mathbb{R}^{S\times d_l}$ 与键矩阵 $\mathbf{K} \in \mathbb{R}^{S\times d_l}$ 经因果掩码 $M \in \mathbb{R}^{S\times S}$ 计算得到注意力权重张量 $\mathbf{A}_i \in \mathbb{R}^{b \times h \times S \times S}$：

$$
\mathbf{A} = \mathrm{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_l}} + M\right)
$$

在自回归解码的每一个时间步，序列的**最后一个位置 `[-1]`** 恰好汇聚了前序所有视觉 Token $v$、文本指令 $t$ 与已生成历史 $g$ 的上下文信息，并直接决定下一个词的预测。因此，SID 直接提取第 $i$ 层解码器在最后一个 Token 位置 `[-1]` 上对所有视觉 Token 索引集合 $v$ 的跨头平均注意力得分，作为每个视觉 Token 与当前预测词的语义相关性评分（式 5）：

$$
\mathrm{Score}_i(v) = \frac{1}{h} \sum_{j=1}^{h} \mathbf{A}_i^{(\cdot, j, \cdot, \cdot)}[-1]\big|_{v} \in \mathbb{R}^{N}
$$

相比于利用视觉编码器内部 `[CLS]` Token 注意力的方法，$\mathrm{Score}_i(v)$ 是在 LLM 解码器内部动态计算的，因而天然具备**文本指令感知（Text-aware）** 与**已生成上下文感知（Context-aware）** 能力——随着生成推进和关注焦点转移，$\mathrm{Score}_i(v)$ 会实时指向当前正在描述的视觉局部区域。

### 2.2 上下文与文本感知 Token 选择（$\text{CT}^2\text{S}$）：为什么保留注意力最低的 10%？

拿到第 $i$ 层对视觉 Token 的自省重要性评分 $\mathrm{Score}_i(v)$ 后，负分支该如何构造受扰动的视觉表示 $v_d$？作者系统对比了三种截然不同的设计维度（图 3、图 4），最终确立了 **$\text{CT}^2\text{S}$（Context and Text-aware Token Selection）** 机制：

1. **做减法（保留低注意力 Token）而非做加法（保留高注意力 Token）**：
   - 如果在分支中保留高注意力 Token $v\!\uparrow$ 并用加法强化 $(1-\alpha)\mathrm{logit}(v) + \alpha\,\mathrm{logit}(v\!\uparrow)$（论文式 6，`Add` 变体），虽然能在简单 Random 子集上维持准确率（`88.9%`），但在 Adversarial 对抗子集上准确率仅为 `79.4%`（远低于 SID 的 `82.6%`，表 2）。原因在于：高注意力 Token 在原始完整分支 $v$ 中本来就已经占据主导地位，`Add` 只是重复奖励了已经很高的前景分数，却**完全没有压制由背景共现激发的幻觉候选词分数**。
   - 反之，如果在负分支中**剪除所有高注意力前景 Token，仅保留 $\mathrm{Score}_i(v)$ 最低的 Top-$k\%$（默认 $10\%$，例如 LLaVA-1.5 中 $576 \times 10\% \approx 58$ 个）视觉 Token** 作为 $v_d$：此时负分支看不见当前询问的核心前景目标（例如看不见图中的“棒球运动员”），但依然能看见周围的次要背景（例如“绿茵草地”和“观众席”）以及前文已生成的体育描述，于是模型内部潜藏的跨模态虚假共现先验被彻底激活，在负分支中高概率预测出 `"football"` 或 `"basketball"` 等关联幻觉词；随后通过对比相减 $(1+\alpha)\mathrm{logit}(v) - \alpha\,\mathrm{logit}(v_d)$，这些共现幻觉词被精准定点清除！
2. **在早期解码层之后（$i=3$）剪枝，而非在输入层（$i=0$）或深层剪枝**：
   - 若在进入解码器前就丢弃全部视觉 Token（即 $0\%$ 保留，退化为 M3ID / VIG 的无图分支），负分支完全丧失视觉场景语境，只能输出与当前图像场景脱节的纯文本高频词，无法针对性地激发特定视觉背景下的共现幻觉；
   - 若在解码器深层（如 $i > 15$）才剪除高注意力视觉 Token，此时视觉信息早已在前序层通过自注意力充分注入到了末尾文本 Token 的隐藏状态中，此时再删视觉 Token 几乎不会改变输出分布（$\mathrm{logit}(v_d) \approx \mathrm{logit}(v)$），对比解码失效；
   - **最佳平衡点位于早期解码层 $i=3$（对于 Q-Former 架构的 InstructBLIP 为 $i=5$）**：前 3 层解码器刚刚完成粗粒度的全局图文语义对齐，使保留下来的 10% 低注意力 Token 携带了基础场景语境，而细粒度的前景实体特征尚未完全泄露到文本末尾 Token 中，此时剪除 90% 高注意力视觉 Token 既能最强烈地诱发关联幻觉，又能让后续第 $4 \sim 32$ 层仅需在极短序列（$58$ 个视觉 Token + 文本 Token）上运行，**直接省去负分支后 29 层中 90% 的视觉计算量**。

### 2.3 SID 完整推理流程总结

在每个自回归生成时间步 $t$，SID 的双分支免训练推理过程如下：
1. **前 $i$ 层共享前向（或并行前向）与自省打分**：将完整视觉 Token $v$、指令 $t$ 与已生成序列 $y_{<t}$ 送入解码器前 $i$ 层（LLaVA-1.5 / Shikra / LLaVA-NeXT 取 $i=3$，InstructBLIP 取 $i=5$），在第 $i$ 层提取末尾位置 `[-1]` 对视觉区域的跨头平均注意力得分 $\mathrm{Score}_i(v)$；
2. **正分支（Original Branch）**：保留全部 $N$ 个视觉 Token $v$ 通过剩余 $L-i$ 层解码器，得到原始输出对数几率 $\mathrm{logit}_\theta(y_t \mid v, t, y_{<t})$；
3. **自省负分支（Self-Introspective Disturbed Branch）**：根据 $\mathrm{Score}_i(v)$ 排序，**仅保留得分最低的 $k\%$（默认 $10\%$）视觉 Token** 构成稀疏背景视觉子集 $v_d$（其余 $90\%$ 视觉 Token 直接从第 $i+1$ 层的 KV Cache / 隐藏状态序列中剔除），通过剩余 $L-i$ 层解码器得到关联幻觉对数几率 $\mathrm{logit}_\theta(y_t \mid v_d, t, y_{<t})$；
4. **对比相减与合理性截断**：在满足自适应合理性约束 $\mathcal{V}_{\text{token}}(y_{<t})$（默认 $\beta = 0.1$）的候选集内，按对比强度 $\alpha$（默认 $\alpha = 1.0$ 或 $0.5$）计算最终修正分布并执行贪心或多项式采样：

$$
p_{\text{SID}}(y_t \mid v, v_d, t, y_{<t}) = \mathrm{softmax}\!\Big[(1 + \alpha)\,\mathrm{logit}_\theta(y_t \mid v, t, y_{<t}) - \alpha\,\mathrm{logit}_\theta(y_t \mid v_d, t, y_{<t})\Big], \quad y_t \in \mathcal{V}_{\text{token}}(y_{<t})
$$

## 3. 实验结果与定量分析

### 3.1 实验设置

- **评测模型（4 大代表性架构，涵盖 7B / 8B / 13B）**：**LLaVA-1.5（7B / 13B）**（MLP 映射，576 视觉 Token）、**InstructBLIP（7B / 13B）**（Q-Former 映射，32 视觉查询 Token）、**Shikra-7B**（支持坐标接地的多模态模型）以及高分辨率动态切图模型 **LLaVA-NeXT-8B**（最高 2880 视觉 Token）。
- **对比基线**：涵盖标准解码（Normal Sampling $^*$ 与 Greedy $^\star$）、LLM 层间对比解码 **DoLa**、注意力惩罚与回滚解码 **OPERA**、指令对比解码 **ICD**、视觉对比解码 **VCD** 以及盲点 Token 对比解码 **AVISC**。

### 3.5 消融实验：Token 选择策略与超参数敏感性

1. **不同 Token 选择策略的正面交锋（附录表 13，LLaVA-1.5 7B Greedy）**：
   - **Normal Greedy**：POPE Random `88.8%` / Adv `79.3%` / $\text{CHAIR}_s$ `49.6` / $\text{CHAIR}_i$ `14.4`；
   - **`SID-High`（在负分支中反过来保留注意力最高的 10% Token）**：Random 跌至 `87.0%`，Adv 跌至 `76.5%`，$\text{CHAIR}_s / \text{CHAIR}_i$ 剧烈恶化至 `57.9 / 25.6`！这直接证实了高注意力 Token 承载的是正确前景视觉依据，若将其放入负分支相减，等于直接抹杀了模型的正确视觉感知；
   - **`SID-Random`（随机保留 10% 视觉 Token）**：Random `88.4%` / Adv `80.9%` / $\text{CHAIR}_s$ `48.6` / $\text{CHAIR}_i$ `13.5`，由于随机采样偶尔会误留前景 Token，效果明显弱于定向保留低注意力 Token；
   - **`AVISC`（同期工作，将各层注意力均值 + 标准差筛出的高注意力“盲点 Token”作为负分支）**：Random `88.4%` / Adv `79.8%` / $\text{CHAIR}_s$ `45.3` / $\text{CHAIR}_i$ `14.7`，全面落后于 **SID（Least-10%）：Random `89.3%` / Adv `83.3%` / $\text{CHAIR}_s$ `44.2` / $\text{CHAIR}_i$ `12.2`**。
2. **剪枝层 $i$ 与保留比例 $k\%$ 消融（图 4）**：在 LLaVA-1.5 7B 上，剪枝层 $i \in \{2, 3, 4\}$、低注意力保留比例 $k\% \in [10\%, 40\%]$ 时性能均高度稳健；当 $k\% = 0\%$（完全丢弃视觉 Token，即 M3ID 式负分支）或 $i \ge 15$（深层剪枝）时，对抗子集准确率均出现明显回落。

## 4. 深度评述：M3ID、VCD 与 SID 的演进脉络对比

将本文（**SID**, ICLR 2025）与前序代表作 **VCD**（CVPR 2024）、**M3ID**（CVPR 2024）及 **AVISC**（ACL 2025 Findings）放在同一坐标系下对比，可以清晰把握免训练多模态对比解码的技术演进逻辑：

| 对比维度 | VCD (CVPR 2024) | M3ID (CVPR 2024) | AVISC (ACL 2025 Findings) | SID (ICLR 2025，本文) |
| :--- | :--- | :--- | :--- | :--- |
| **幻觉归因假设** | 视觉输入退化诱发统计偏置与语言先验 | 生成长度增长导致视觉记忆按指数衰减（条件稀释） | 少数不携带目标信息的“视觉盲点 Token”垄断了过高注意力 | 早期跨模态交互后，次要背景视觉上下文与文本历史共同触发共现联想幻觉 |
| **负分支构造方式** | 对整张输入图像施加多步高斯扩散噪声 | 直接丢弃全部视觉 Token（保留纯文本提示与前缀） | 保留注意力高于 $\mu + \lambda\sigma$ 的视觉盲点 Token，掩码其余 Token | 前 $i=3$ 层正常交互，之后**仅保留注意力最低的 10% 视觉 Token** |
| **对比权重机制** | 固定常数 $\alpha$ + APC 截断 | 随步数 $t$ 指数增长的 $\frac{1-\gamma_t}{\gamma_t}$ + 置信度门控 | 固定常数 $\alpha$ + APC 截断 | 固定常数 $\alpha$ + APC 截断 |
| **Greedy 解码兼容性** | 简单子集（POPE Random）性能倒退 | 兼容，但在极短回答或高置信度词上受门控限制 | 兼容，但盲点假设在普通自然图像上可能误伤前景 | **完全兼容，简单与对抗子集双双提升** |
| **相对单分支推理开销** | $\sim 2.0\times$ 耗时（$+1.08\text{ GB}$ 显存） | $\sim 1.4\times$ 耗时（负分支无视觉 Token，但破坏 RoPE 位置对齐） | $\sim 2.0\times$ 耗时（掩码置零未减少序列长度） | **$\sim 1.35\times$ 耗时（比 VCD 快 ~30%，仅 $+94\text{ MB}$ 显存）** |

**局限性与未来方向**：
1. **极端密集场景下的注意力泄漏**：当图像中包含大量同类密集目标或提问涉及全局计数（Counting）时，“最低 10% 注意力 Token”中仍可能包含部分目标边缘特征，或者前 $i=3$ 层已经将部分前景信息混合进了全局上下文中；
2. **与时变权重的潜在结合空间**：SID 解决了“空间维度上该保留哪些视觉 Token 来构造最准的负分支”，而 M3ID 解决了“时间维度上随着生成变长该如何动态加大对比力度”。将 SID 的 $\text{CT}^2\text{S}$ 负分支构造与 M3ID 的时变放大系数 $\frac{1-\gamma_t}{\gamma_t}$ 相结合，是长文档多模态生成中极具潜力的组合方案。
